# Free Reviewer and Full Review System

The free reviewer is a complete, permanently reusable single-essay reviewer. It has no essay counter, expiry date, hidden online activation, or intentionally weakened scoring.

The future full system is a separate product for learners who want to connect reviews over time.

| Capability | Free reviewer | Full review system |
|---|:---:|:---:|
| Unlimited single-essay reviews | Yes | Yes |
| Four training reference scores | Yes | Yes |
| Exact essay evidence | Yes | Yes |
| Three priority problems | Yes | Yes |
| Next-draft checklist | Yes | Yes |
| Pre-writing question analysis | No | Planned |
| Structured error cards | No | Planned |
| Learner-first revision workflow | No | Planned |
| Targeted practice generation | No | Planned |
| Repeated-error tracking across essays | No | Planned |
| Weekly review and training focus | No | Planned |
| Notion review notebook | No | Planned |

## Product boundary

The free reviewer answers:

> What are the three most important problems in this essay?

The full system is designed to answer:

> How do I turn today’s three problems into practice, review them later, and check whether they return in my next essays?
