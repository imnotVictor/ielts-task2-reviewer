# 免费批改器与完整批改系统

[返回中文 README](../README.md)

免费批改器是一款功能完整、可以永久重复使用的单篇作文批改工具。它没有作文次数限制、到期时间、隐藏的在线激活，也不会故意降低评分质量。

未来的完整系统是面向希望长期串联多次批改记录的学习者所设计的独立产品。

| 功能 | 免费批改器 | 完整批改系统 |
|---|:---:|:---:|
| 不限次数的单篇作文批改 | 有 | 有 |
| 四项训练参考分 | 有 | 有 |
| 引用作文原文证据 | 有 | 有 |
| 三个优先问题 | 有 | 有 |
| 下一稿检查清单 | 有 | 有 |
| 写作前审题 | 无 | 计划提供 |
| 结构化错题卡 | 无 | 计划提供 |
| 学习者优先的修改流程 | 无 | 计划提供 |
| 针对性练习生成 | 无 | 计划提供 |
| 跨作文重复错误追踪 | 无 | 计划提供 |
| 每周复盘与训练重点 | 无 | 计划提供 |
| Notion 批改错题本 | 无 | 计划提供 |

## 产品边界

免费批改器回答：

> 这篇作文中最重要的三个问题是什么？

完整系统计划回答：

> 我怎样把今天的三个问题转化成练习，之后进行复习，并检查这些问题是否又出现在下一篇作文中？
