# IELTS Task 2 Reviewer

IELTS Task 2 Reviewer is a reusable Prompt and Codex Skill for structured feedback on a single IELTS Writing Task 2 essay.

## Current release

Version: `1.0.0`

The reviewer is designed for unlimited use: there is no essay counter, expiry date, or artificial trial limit.

## What it provides

- a training reference score for each of the four IELTS Writing criteria;
- exact evidence quoted from the submitted essay;
- exactly three priority problems;
- concise actions for the next draft;
- an explicit scoring limitation.

The complete Prompt, Skill, examples, and instructions are being prepared in this repository.

## Scoring boundary

Every score is an AI-generated training reference score. It is not an official IELTS result, does not guarantee score improvement, and should be checked against official guidance or qualified human feedback when accuracy matters.
