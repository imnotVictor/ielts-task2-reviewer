# IELTS Task 2 写作批改器

IELTS Task 2 写作批改器是一套可以重复使用的通用 Prompt 和 Codex Skill，用于对单篇 IELTS Writing Task 2 作文提供结构化反馈。

## 当前版本

版本：`1.0.0`

免费版不限使用次数，没有作文次数限制、到期时间或人为设置的试用上限。

## 提供的反馈

- IELTS Writing 四项标准的训练参考分；
- 引用作文原文作为判断证据；
- 恰好三个最优先处理的问题；
- 下一稿可以执行的简短建议；
- 明确的 AI 评分边界。

完整 Prompt、Skill、示例和说明正在本仓库中制作。

## 评分边界

所有分数均为 AI 生成的训练参考分，不是官方 IELTS 成绩，不保证提分。在准确性非常重要时，请同时参考官方说明或合格教师的人工反馈。
